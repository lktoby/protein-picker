## 当日の準備（ライブデモの場合）

```bash
# 1. 起動（ビルドを含むので数分かかる。発表の 10 分前には済ませる）
docker compose up --build

# 2. 初回のみ: テーブル作成とサンプルデータ投入（別ターミナル）
npm run db:setup

# 3. ブラウザで開いておく
open http://localhost:3000
```

デモの推奨ルート（スライド 4 枚目と対応）:

1. `/recommend` で **「筋肉をつけたい」＋「運動後」＋「価格の安さ重視」** を選ぶ
   → 1 位に大容量の低単価商品が来る。**「価格の安さ重視は実際の価格で採点している」**（RV-09）が伝わる条件
2. カルーセルを 1 つ進めて「詳細・購入方法を見る」
3. 商品詳細で **「最安」バッジ**と **「商品 N円 + 送料 M円」** を指さす
4. 「このショップで購入」→ カード欄が **編集できない**ことと **ランダム生成ボタン**を見せる → 注文を確定
5. 注文履歴で **お届け状況バッジ**と **「お問い合わせ」** を開く
6. 最後にヘッダー右のアイコンで **ダークモード**に切り替える

> 注意: 注文履歴はデータベースに保存されるため、リハーサルで作った注文が残ります。
> 空の状態から見せたい場合は `npm run db:seed` の前に注文テーブルを空にしてください。
