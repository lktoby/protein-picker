# onboarding — インターン向け導入資料

このリポジトリで「AIドリブンな開発」を体験してもらう前に、**最初に読む**資料です。

- このディレクトリ … 考え方の説明と、開発環境（Claude Code）のセットアップ
- リポジトリ直下の `docs/` … 実際に**作るアプリ**の成果物（要件・設計・実装メモなど）。性質が違うので分けています。

## 目次

1. スライドで考え方を理解する
2. Claude Code をセットアップする
3. Docker でアプリを起動する
4. Git をセットアップする
5. 開発フローを進める

---

## 1. スライドで考え方を理解する

まず `slides.html` を開いて、「どこを人間が握り、どこを AI に任せるか」を掴んでください。

- **見かた**: `slides.html` を **ブラウザで開くだけ**（ダブルクリック）。ビルド不要。
  - [reveal.js](https://revealjs.com/) 製の単一 HTML。`← → / Space` でめくる。
  - 図はHTMLに埋め込み済みなので、他ファイルは不要。
- **PDF が欲しいとき**: ブラウザの印刷（PDF保存）で出力できる。
  - もしくは URL 末尾に `?print-pdf` を付けて開き、印刷する。
- **編集するとき**: `slides.html` を直接編集する（テキストエディタで可）。

## 2. Claude Code をセットアップする

この開発フローは **Claude Code**（Anthropic の CLI）で進めます。

**セットアップ手順は [`claude_setup.md`](./claude_setup.md) を参照してください。**
（インストール、配布された API キー／環境変数の設定、起動確認までをまとめています）

セットアップが済んだら、プロジェクトのディレクトリで `claude` を起動します。

```bash
cd /path/to/ai-flow-sample-for-intern
claude
```

### このリポジトリが自動で効く仕組み
Claude Code は起動時に、次を自動で読み込みます（設定は不要）。

- **`CLAUDE.md`**（リポジトリ直下）… このプロジェクトの開発フローと承認ルール
- **`.claude/commands/*.md`** … 5つのカスタムコマンド（スラッシュコマンド）

そのため、起動後すぐ `/requirements` などを実行できます。使えるコマンドは `/help` で確認できます。

## 5. 開発フローを進める

セッション中に、次の順でスラッシュコマンドを実行します。
（各コマンドの詳細・承認ルールはリポジトリ直下の `CLAUDE.md` を参照）

```
/requirements      要件定義（人間と壁打ち → 承認 必須 ●）
   ↓
/prototype         デモ作成（モックで動く画面）→ 関係者レビュー 必須 ●
   ↓                    └─ 要件の漏れが見つかったら /requirements に戻る
/design            詳細設計（AI 自走 ○）
   ↓
/implement         実装・単体テスト（TDD、AI 自走 ○）
   ↓
/acceptance-test   受け入れテストシナリオ作成 → 人間が出荷判定 ●
```

`/prototype` は、**設計・実装に入る前に「動くもの」を関係者に見せて要件の漏れを潰す**工程です。
ここで手戻りを吸収しておくと、後工程の作り直しが大きく減ります。

### AI からの質問は「質問シート」で届きます

このリポジトリでは、**AI からの確認はチャットではなく `docs/xx-.../questions.md` というファイルに書き出されます。**
AI が「質問を書き出しました」と言って止まったら、そのファイルを開いて各質問の **「回答」欄に記入**し、
チャットで「回答しました」と伝えてください。AI が読み直して続きを進めます。

質問と回答がファイルに残るので、後から「なぜこの仕様にしたか」を追えます。
落ち着いて考えてから、あるいは関係者に確認してから回答できるのも狙いです。

まずは `/requirements` を実行して、作りたいアプリの壁打ちから始めてください。
